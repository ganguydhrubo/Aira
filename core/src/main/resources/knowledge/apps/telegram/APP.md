## What it is
Telegram is a messaging app, package `org.telegram.messenger`. For the website, see `telegram.org`.

## Screens
It has Chats (conversation list), Contacts and a new message entry; for a new message you can pick a person from contacts or search. The page shown on opening is not always Chats.

## Features
- **Read messages**: find the target in the chat list and open it, then scroll to see the history; each message has a sender and time. Groups, channels and contacts are different kinds of object.
- **Send messages**: type in an existing chat, or pick the recipient from Contacts or the new message entry. After sending, a new message bubble appears in the chat. The contacts page shows contact details.
