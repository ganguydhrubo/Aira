## What it is
A messaging service used worldwide. The web version `web.whatsapp.com` shares the same account with the phone and desktop apps.

## Pages and URLs
Web entry `https://web.whatsapp.com/`. When not linked, the page shows a QR code; scan it with "Linked devices" in WhatsApp on the phone. After signing in, the chat list, search and new chat button are on the left and the chat window on the right. The interface language follows the browser.

## Features
- **Read**: the chat list shows the title and last message; open a chat to see the text and times. In group chats you can see which member sent each message.
- **Send messages**: in an existing chat, type in the box at the bottom and send; for a new chat, go through New chat or search for the contact.

## Known behaviour
Linking a device uses the QR code, which is a different check from the phone number code. With the newer linking method, the phone does not always need to stay online.
