## What it is
A messaging service with private chats, groups and channels. The web version is at `web.telegram.org`; the matching app guide is `telegram`. You must be signed in to use it.

## Pages and URLs
Web version `https://web.telegram.org/k/`: search and the chat list on the left, the chat on the right. Sign in by scanning a QR code, or with phone number plus code; if two-step verification is on, a password is also needed.

## Features
- **Read**: the chat list shows the last message and its time. Inside a chat you can scroll up for older messages and see the sender, group members and dates. The preview in the list is not the full text.
- **Send**: type directly in an existing chat; for a new chat, find the person from search, contacts or new message.

## Known behaviour
- Groups, channels and contacts can have the same name.
- Opening a chat may change its unread status.
